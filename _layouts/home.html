For the last 4.5 years, I am working as a C++ developer in Siemens DISW, developing and improving the finite element framework in Simcenter StarCCM+.

Traditionally StarCCM+ is a finite volume based CFD code. Over the last years, fully capable finite element based framework is developed. My role is to implement and improve the framework components that serves solid mechanics and electromagnetism based physics.

I architectured and improved the p-FEM related infrastructre. With this change, more physics can easily use p-FEM, without additional effort from physics developers.

Post-processing of p-FEM fields is challenging, especially in FVM based framework. I improved the post-processing capabilities by performance improvements and by implementing high accuracy FE-based integration reports.

In order to reuse common framework components, I modernized the FE-based expression template infrastructre by removing virtualness and refactoring it to variant based approach.

I worked on improving FSI stabilization capabilities through Dynamic Stabilization method, and automatic parameter computations.

I worked as a developer in open-source multi-physics coupling library preCICE.

Here, I developed features such as data mapping on interfaces that are conserved, tracking the interface integral values, multi-coupling of arbitrary number of physics solvers.

For a short time, I worked in PhiFlow, a fully differentiable solver developed with JAX for Physics-Informed Neural Network research.

I analyzed memory transfer patterns between CPU and GPU in higher level and identified bottlenecks, which are used to improve the performance of the solver in the upcoming versions.
